# HyperCast v2.0.0 Beta4

© DylanLiao — 把 Android 的系統音訊，以立體聲串流到 AirPlay 裝置（HomePod、Apple TV、支援 AirPlay 的喇叭與電視）。
Apple 液態玻璃風格介面、小米 HyperIsland 狀態顯示、可調音訊延遲與觸感回饋。

## 開始使用
1. 手機和 AirPlay 裝置連上同一個 Wi-Fi。
2. 開啟 HyperCast，從「我的裝置」點選要播放的裝置，並允許螢幕錄製（只用來擷取系統聲音，不會錄影）。
3. 在畫面上調整音量；要停止時按「中斷連接」。

## 功能
- **同時播放到兩台裝置**：串流中再點另一台即可加入（最多 2 台），再點一次移除。兩台都是單顆喇叭時，可選「兩台都播立體聲」或「左右分開」。
- **HomePod 立體聲組、Apple TV**：需要配對碼時會跳出輸入框，配對成功後會記住，下次不用再輸入。
- **音訊延遲**：聲音和畫面不同步時，到「設定 → 音訊延遲」微調（每次 50 ms，串流中即可調整）。
- **音量**：預設 25%；可選擇是否同步手機音量鍵、是否開啟「音量平衡」（讓不同歌曲的大小聲接近）。
- **HyperIsland（上島）— 四種顯示方式，在「設定 → HyperIsland」切換**：
  - **一般通知**：只有一則玻璃通知（音量－／＋、靜音、中斷）。不用焦點通知、不建立媒體工作階段，最單純。
  - **焦點通知・純顯示（短暫）**（預設）：小米焦點通知只顯示狀態與音量，沒有按鈕、沒有媒體工作階段；內容改變時島彈出約 6 秒就收起。HyperOS 3 以上。
  - **焦點通知・純顯示（持續）**：島一直顯示狀態（低優先級）。HyperOS 2 也能用，但可能擋住其他通知。
  - **媒體通知（實驗）**：Beta 1 的做法。預設不再理會系統送來的「暫停」；要用島上的暫停鍵靜音，需另外打開「播放・暫停＝靜音」。
  - 焦點通知模式可再打開「閒置時顯示『未連接』」（預設關；島 6 秒、通知 15 秒後自動消失）。
- **外觀**：幻彩、純白、純黑三種主題，都帶液態玻璃效果。
- **觸感**：每次點觸都有對應震動，滑桿與延遲調整到臨界值時有明顯回饋；可在設定關閉。
- **完全關閉程式**：設定 → 應用程式，會中斷連接並結束所有背景服務。

## 回報問題
遇到無法連線或沒有聲音時：
1. 到「設定 → 意見回饋」，依指示先閱讀同意書並開啟日誌記錄，再重現一次問題。
2. 記錄滿 5 分鐘會有通知提醒你回來傳送。
3. 回到「設定 → 意見回饋 → 傳送意見與日誌給開發者」，會開啟郵件 App，日誌已附上，主旨自動使用日誌的時間。

日誌只存在你的手機，不會自動上傳；IP 末段、MAC、UUID 會遮蔽，不含配對碼、金鑰、音訊內容與 Wi-Fi 名稱。
聯絡開發者：dylanliao.hyper@gmail.com

## 已知限制
- 只能擷取允許被錄製的 App 聲音（部分 App 與受版權保護的內容會是靜音）。
- 尚不支援設有密碼的 AirPlay 2 接收端。
- 左右聲道分配尚未在所有裝置上驗證。

## Beta 2 修正：一直自動暫停
- **原因（從程式推斷，尚未在你的手機上驗證）**：Beta 1 為了上島改用「媒體通知」，建立了媒體工作階段，並把收到的「暫停」一律當成靜音接收端；
  島、系統或其他 App 只要對這個工作階段送出暫停（再加上靜音時狀態會變成「已暫停」），聲音就停了。
- **修正**：預設不再處理系統送來的暫停 / 播放，工作階段永遠回報「播放中」，也不公開暫停鍵；改回預設用「焦點通知・純顯示」，完全沒有媒體工作階段。
- 媒體模式每次收到的島 / 系統指令都會寫進診斷日誌（`MEDIA` 類別），若還是有問題，匯出日誌就能看出是誰送了什麼。

## Beta 2（續）：「焦點通知讓其他 App 的一般通知被隱藏」排查
對照小米官方超級島文件（dev.mi.com → 開發指南）後的修改：
- 官方的 `islandFirstFloat`（通知第一次出現時是否自動展開成大卡片）**預設為 true**，舊版從來沒設定它，所以島每次出現都會展開，可能蓋住 / 擠掉其他 App 的橫幅通知。現在預設送 `false`（只出摘要態）。
- 舊版的 `islandPriority` 不在官方欄位清單裡，應該沒有任何作用（之前說它能「讓其他 App 的島優先」是我的誤判），已移除。
- 「短暫」模式：除了 `islandTimeout`，彈出約 N 秒後會再送一次官方的 `dismissIsland`，明確把摘要態的島收起來（N 可調：3～30 秒）。
- 新增「焦點通知進階」選項（設定 → HyperIsland，選了焦點通知時出現）：首次出現自動展開、獨立焦點通知（可滑掉）、低重要性頻道、持續性（updatable）。
- **尚未確認真正的原因**：官方文件沒有說明焦點通知會隱藏其他通知，所以這些是依文件欄位做的排查選項，需要在你的手機上實測。每次附上島參數都會寫進診斷日誌（`ISLAND`）。

## Beta3：「通知全被擋住、滑不掉」排查
症狀：開始串流後，所有 App 的通知像被鎖定畫面擋住，內容看不到、也滑不掉。
- **不是音量鍵同步造成的**：它只是註冊「音量變化廣播」與「系統設定觀察者」，完全不碰通知與視窗。為了讓你能乾淨地 A/B 測試，
  「設定 → 音訊 → 同步手機音量鍵」關閉時會**完全不註冊**接收器 / 觀察者（以前只是收到後忽略），串流中切換立刻生效。
- **實際修正的錯誤**：對照小米官方文件（dev.mi.com → 小米超級島 → 開發指南），`islandFirstFloat`、`timeout` 屬於「通知屬性」（`param_v2` 這一層），
  之前把 `islandFirstFloat` 放進 `param_island`，系統不認得，所以一直用官方預設 `true`（每次都展開成大卡片）。現已移到正確位置；
  短暫模式另外送 `timeout`（官方預設 720 分鐘＝12 小時）。
- **最可能的真正原因（待你的手機驗證）**：HyperCast 為了擷取系統聲音必須啟動 MediaProjection。Android 15 起，螢幕分享 / 錄製期間系統會隱藏通知的私人內容
  （Google 安全部落格），HyperOS 3 另有「投屏時隱藏隱私項目」。這與通知模式無關，所以不論用媒體通知或焦點通知都會發生。
  Beta3 的日誌會記下串流前後的鎖屏狀態、鎖屏通知設定、「螢幕分享保護」開發者選項與本 App 的通知狀態，方便對照。

## Beta3：診斷日誌改為「逐項同意」
- 設定 → 診斷 → 日誌記錄，會先進入「診斷資料與權限」頁：列出 11 項資料（HyperOS 4 風格 2.5D 圓角圖示）、每項會收集的內容、需要的權限與目前狀態。
  **每一項都要同意（逐項開啟或「全部同意」）才能按「同意並開始記錄」**；同意之前一筆都不收集。關閉日誌＝撤回全部同意。
- 11 項：手機與 App 資訊、App 設定、網路環境、區網裝置探索、AirPlay 連線與串流、音訊擷取與音量、通知與焦點通知、系統隱私保護與鎖屏狀態、
  電池／背景限制／效能、當機與異常結束（含系統記錄的上次結束原因）、概略位置。
- 每筆日誌帶標籤，寫入前檢查所屬項目是否已同意；舊版（同意書版本 1）的同意不算數，更新後需重新同意。
- 串流開始／停止各記一次完整快照，串流中每分鐘取樣電池、發熱、記憶體與鎖屏狀態。
- 一律不收集：音訊內容、通知標題與內容、其他 App 的資料、配對碼、加密金鑰、Wi-Fi 名稱 / 密碼 / BSSID。

## Beta3：蘋果官方 HomePod 圖示
本專案**不內附**蘋果的官方圖檔（蘋果擁有其著作權與商標）。要改用官方圖示，請自行向蘋果取得並遵守其使用規範，再放進
`app/src/main/res/drawable-nodpi/`，檔名固定：
- `homepod_official.png`（HomePod）
- `homepod_mini_official.png`（HomePod mini）

放好重新建置後，App 內裝置清單與 HyperIsland / 通知會自動改用（通知的島圖示會被單色化為剪影）。沒放時維持內建繪製的樣式。

## Beta4：通知被擋診斷（設定 → 通知被擋住？ → 通知被擋診斷）
Beta3 的日誌證明串流本身很穩，但無法分辨「通知被擋住」的原因；Beta4 加了能直接分辨的實驗與工具。
- **兩階段實驗（不需要連線任何裝置）**：階段 A 只取得螢幕擷取授權（MediaProjection）；階段 B 再加上音訊擷取（設定和串流相同，但不連線、不送出聲音）。
  每階段下拉通知欄回答「正常 / 被擋住」，頁面會給出判斷：
  - 階段 A 就被擋 → 系統的螢幕分享保護（Android 15 起，螢幕分享 / 錄製期間隱藏通知內容），和 HyperCast 的通知、串流無關。
  - 階段 A 正常、B 被擋 → 觸發點是音訊擷取。
  - 兩階段都正常 → 問題在串流或 HyperCast 的通知，改用「極簡通知」再測。
- **極簡通知（診斷用）**：新的通知方式，只有標題與一行文字——沒有自訂版面、按鈕、焦點通知與媒體工作階段。
- **關閉螢幕分享保護的捷徑**：一鍵開啟「開發者選項」「關於手機」「投屏」設定。
  進階：用電腦執行一次 `adb shell pm grant com.hypercast.airplay android.permission.WRITE_SECURE_SETTINGS` 授權後，
  頁面可直接「停用保護 / 還原」（系統全域設定 `disable_screen_share_protections_for_apps_and_notifications`）。
  停用後螢幕分享 / 錄製時系統不再隱藏通知與敏感內容；HyperCast 只擷取聲音。小米手機要先開「USB 偵錯（安全設定）」才能授權。
- **日誌**：新增「標記：現在通知被擋住」（首頁與設定頁，記錄中才會出現），按下會寫入標記並拍下通知 / 鎖屏 / 電源 / 網路快照；
  串流開始後 2.5 秒補讀一次通知（上一版太早讀，永遠是 0 則）；每分鐘取樣也會記通知數量；`serialNumber`、公開金鑰 `pk` 現在會遮蔽。
