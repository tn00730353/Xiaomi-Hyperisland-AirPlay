# HyperCast v2.0.0 Beta5

© DylanLiao — 把 Android 的系統音訊，以立體聲串流到 AirPlay 裝置（HomePod、Apple TV、支援 AirPlay 的喇叭與電視）。
Apple 液態玻璃風格介面、小米超級島（HyperIsland）常駐狀態顯示、可調音訊延遲與觸感回饋。

## 開始使用
1. 手機和 AirPlay 裝置連上同一個 Wi-Fi。
2. 開啟 HyperCast，從「我的裝置」點選要播放的裝置，並允許螢幕錄製（只用來擷取系統聲音，不會錄影）。
3. 在畫面上調整音量；要停止時按「中斷連接」。

## 功能
- **同時播放到兩台裝置**：串流中再點另一台即可加入（最多 2 台），再點一次移除。兩台都是單顆喇叭時，可選「兩台都播立體聲」或「左右分開」。
- **HomePod 立體聲組、Apple TV**：需要配對碼時會跳出輸入框，配對成功後會記住，下次不用再輸入。
- **音訊延遲**：聲音和畫面不同步時，到「設定 → 音訊延遲」微調（每次 50 ms，串流中即可調整）。
- **音量**：預設 25%；可選擇是否同步手機音量鍵、是否開啟「音量平衡」（讓不同歌曲的大小聲接近）。
- **超級島（HyperOS 3 以上）**：串流期間常駐顯示連線狀態、音量與裝置圖示，純顯示、沒有按鈕、不建立媒體工作階段。
  通知列另有一則玻璃通知（音量－／＋、靜音、中斷）。非小米裝置或沒開焦點通知權限時，只會顯示這則一般通知。
- **外觀**：幻彩、純白、純黑三種主題，都帶液態玻璃效果。
- **觸感**：每次點觸都有對應震動，滑桿與延遲調整到臨界值時有明顯回饋；可在設定關閉。
- **完全關閉程式**：設定 → 應用程式，會中斷連接並結束所有背景服務。

## 串流時其他 App 的通知被隱藏、滑不掉？
**這不是 HyperCast 的通知造成的，是 Android 15 起的「螢幕分享保護」。**
HyperCast 要擷取系統聲音，必須啟動 Android 的螢幕擷取授權（MediaProjection，只擷取聲音、不擷取畫面）；
系統會把它當成螢幕分享，把所有通知的內容隱藏起來，看起來就像被鎖定畫面擋住。

解法：開啟「開發者選項」→ 打開「停用螢幕分享保護」（只要設定一次）。沒有開發者選項時，先到「關於手機」連點「OS 版本」7 次。
設定頁「通知被隱藏？」有直接開啟這些頁面的捷徑。

進階：若開發者選項裡找不到這個開關，可在電腦上執行一次
`adb shell pm grant com.hypercast.airplay android.permission.WRITE_SECURE_SETTINGS`
（小米手機要先開「USB 偵錯」與「USB 偵錯（安全設定）」），之後在設定頁「通知被隱藏？→ 進階」可一鍵「停用保護 / 還原」
（系統全域設定 `disable_screen_share_protections_for_apps_and_notifications`）。
停用後，螢幕分享 / 錄製時系統不再隱藏通知與 App 的敏感內容（例如驗證碼）；之後若要用別的 App 把螢幕分享給別人，請先還原。

## 回報問題
遇到無法連線或沒有聲音時：
1. 到「設定 → 意見回饋」，依指示開啟日誌記錄。會先進入「診斷資料與權限」頁，列出 11 項要收集的資料與所需權限，
   **每一項都同意（逐項開啟或「全部同意」）才會開始記錄**；關閉日誌即撤回全部同意。
2. 重現一次問題；記錄滿 5 分鐘會有通知提醒你回來傳送。
3. 回到「設定 → 意見回饋 → 傳送意見與日誌給開發者」，會開啟郵件 App，日誌已附上，主旨自動使用日誌的時間。

日誌只存在你的手機，不會自動上傳。IP 末段、MAC、UUID、序號與公開金鑰會遮蔽；不含配對碼、加密金鑰、音訊內容、通知內容與 Wi-Fi 名稱。
裝置名稱可能含有人名，分享日誌前請自行確認。

## 蘋果官方 HomePod 圖示
本專案**不內附**蘋果的官方圖檔（蘋果擁有其著作權與商標）。要改用官方圖示，請自行向蘋果取得並遵守其使用規範，再放進
`app/src/main/res/drawable-nodpi/`，檔名固定：`homepod_official.png`（HomePod）、`homepod_mini_official.png`（HomePod mini）。
放好重新建置後，App 內裝置清單與超級島 / 通知會自動改用（島與通知的圖示會被單色化為剪影）；沒放時使用內建繪製的樣式。

## 已知限制
- 只能擷取允許被錄製的 App 聲音（部分 App 與受版權保護的內容會是靜音）。
- 尚不支援設有密碼的 AirPlay 2 接收端。
- 左右聲道分配尚未在所有裝置上驗證。
