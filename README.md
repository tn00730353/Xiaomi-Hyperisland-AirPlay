# HyperCast v2.0.0 Beta 2

© DylanLiao — 把 Android 的系統音訊，以立體聲串流到 AirPlay 裝置（HomePod、Apple TV、支援 AirPlay 的喇叭與電視）。
Apple 液態玻璃風格介面、小米 HyperIsland 狀態顯示、可調音訊延遲與觸感回饋。

## 開始使用
1. 手機和 AirPlay 裝置連上同一個 Wi-Fi。
2. 開啟 HyperCast，從「我的裝置」點選要播放的裝置，並允許螢幕錄製（只用來擷取系統聲音，不會錄影）。
3. 在畫面上調整音量；要停止時按「中斷連接」。

## 功能
- **同時播放到兩台裝置**：串流中再點另一台即可加入（最多 2 台），再點一次移除。兩台都是單顆喇叭時，可選「兩台都播立體聲」或「左右分開」。
- **HomePod 立體聲組、Apple TV**：需要配對碼時會跳出輸入框，配對成功後會記住，下次不用再輸入。
- **音訊延遲**：聲音和畫面不同步時，到「設定 → 音訊延遲」微調（每次 50 ms，串流中即可調整）。
- **音量**：預設 25%；可選擇是否同步手機音量鍵、是否開啟「音量平衡」（讓不同歌曲的大小聲接近）。
- **HyperIsland（上島）— 四種顯示方式，在「設定 → HyperIsland」切換**：
  - **一般通知**：只有一則玻璃通知（音量－／＋、靜音、中斷）。不用焦點通知、不建立媒體工作階段，最單純。
  - **焦點通知・純顯示（短暫）**（預設）：小米焦點通知只顯示狀態與音量，沒有按鈕、沒有媒體工作階段；內容改變時島彈出約 6 秒就收起。HyperOS 3 以上。
  - **焦點通知・純顯示（持續）**：島一直顯示狀態（低優先級）。HyperOS 2 也能用，但可能擋住其他通知。
  - **媒體通知（實驗）**：Beta 1 的做法。預設不再理會系統送來的「暫停」；要用島上的暫停鍵靜音，需另外打開「播放・暫停＝靜音」。
  - 焦點通知模式可再打開「閒置時顯示『未連接』」（預設關；島 6 秒、通知 15 秒後自動消失）。
- **外觀**：幻彩、純白、純黑三種主題，都帶液態玻璃效果。
- **觸感**：每次點觸都有對應震動，滑桿與延遲調整到臨界值時有明顯回饋；可在設定關閉。
- **完全關閉程式**：設定 → 應用程式，會中斷連接並結束所有背景服務。

## 回報問題
遇到無法連線或沒有聲音時：
1. 到「設定 → 意見回饋」，依指示先閱讀同意書並開啟日誌記錄，再重現一次問題。
2. 記錄滿 5 分鐘會有通知提醒你回來傳送。
3. 回到「設定 → 意見回饋 → 傳送意見與日誌給開發者」，會開啟郵件 App，日誌已附上，主旨自動使用日誌的時間。

日誌只存在你的手機，不會自動上傳；IP 末段、MAC、UUID 會遮蔽，不含配對碼、金鑰、音訊內容與 Wi-Fi 名稱。

## 已知限制
- 只能擷取允許被錄製的 App 聲音（部分 App 與受版權保護的內容會是靜音）。
- 尚不支援設有密碼的 AirPlay 2 接收端。
- 左右聲道分配尚未在所有裝置上驗證。

## Beta 2 修正：一直自動暫停
- **原因（從程式推斷，尚未在你的手機上驗證）**：Beta 1 為了上島改用「媒體通知」，建立了媒體工作階段，並把收到的「暫停」一律當成靜音接收端；
  島、系統或其他 App 只要對這個工作階段送出暫停（再加上靜音時狀態會變成「已暫停」），聲音就停了。
- **修正**：預設不再處理系統送來的暫停 / 播放，工作階段永遠回報「播放中」，也不公開暫停鍵；改回預設用「焦點通知・純顯示」，完全沒有媒體工作階段。
- 媒體模式每次收到的島 / 系統指令都會寫進診斷日誌（`MEDIA` 類別），若還是有問題，匯出日誌就能看出是誰送了什麼。

## Beta 2（續）：「焦點通知讓其他 App 的一般通知被隱藏」排查
對照小米官方超級島文件（dev.mi.com → 開發指南）後的修改：
- 官方的 `islandFirstFloat`（通知第一次出現時是否自動展開成大卡片）**預設為 true**，舊版從來沒設定它，所以島每次出現都會展開，可能蓋住 / 擠掉其他 App 的橫幅通知。現在預設送 `false`（只出摘要態）。
- 舊版的 `islandPriority` 不在官方欄位清單裡，應該沒有任何作用（之前說它能「讓其他 App 的島優先」是我的誤判），已移除。
- 「短暫」模式：除了 `islandTimeout`，彈出約 N 秒後會再送一次官方的 `dismissIsland`，明確把摘要態的島收起來（N 可調：3～30 秒）。
- 新增「焦點通知進階」選項（設定 → HyperIsland，選了焦點通知時出現）：首次出現自動展開、獨立焦點通知（可滑掉）、低重要性頻道、持續性（updatable）。
- **尚未確認真正的原因**：官方文件沒有說明焦點通知會隱藏其他通知，所以這些是依文件欄位做的排查選項，需要在你的手機上實測。每次附上島參數都會寫進診斷日誌（`ISLAND`）。
